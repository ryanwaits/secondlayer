Transport and nonce hardening: one `timeout` now covers headers and body, so a stalled response rejects with a new `TimeoutError` (`method`, `url`, `timeout`, `attempt`) instead of hanging, and a rejected fetch never leaves a live timer behind; `RequestOptions.signal` cancels a request from the caller's side and is never retried; `HttpRequestError` carries `url` and `method`. Broadcasts go out once (`retryCount: 0`) and a timed-out broadcast asks the node for the tx before failing. `resolveFee` returns `{ fee, tier }`, floors only on `NoEstimateAvailable` and rethrows every other estimator failure. `NonceStore.release(key, nonce)` (memory, Redis, Postgres) hands a nonce back when a send fails before the node accepts it, so `FeeTooLow` or an estimator outage no longer strands later transactions; `contract.buildCall` reads the confirmed nonce instead of consuming the manager. `multicall` caps reads in flight (`concurrency`, default 8). A canonical-only status source stretches `droppedGracePeriod` to the wait timeout.

BREAKING: `indexSource`/`indexTxSource` go through the client transport (retries, timeout, typed errors) and no longer accept `fetchImpl`. The hosted `https://api.secondlayer.tools` default is gone: `baseUrl` defaults to the transport URL, and a missing URL, a Hiro transport, or a host that answers `/v1/index` with a non-JSON 404 rejects with `IndexSourceConfigError` (exported) instead of degrading to the confirmed nonce; a `baseUrl` on another host gets the transport's retry and timeout policy only, never its `apiKey` or `fetchOptions`. `apiKey` is now sent as `Authorization: Bearer` instead of `x-api-key`, matching what the instance accepts.
