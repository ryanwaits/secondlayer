# Verified archive

Check your chain history against a signed canonical archive, repair what diverges, or restore a fresh instance from it.

## Check your data

```bash
sl verify --against https://pub-08fa583203de40b2b154e6a56624adc2.r2.dev/secondlayer/mainnet/canonical/v1/latest.json
```

Read-only. Nothing leaves your machine — your database computes digests locally and only those are compared. The full mainnet chain checks in well under a minute.

Clean output exits `0`. Divergence names the ranges:

```
⚠ 1 of 175 ranges diverge from the archive.

RANGE              DATASET  STATUS        EXPECTED  LOCAL
-----------------  -------  ------------  --------  -----
8500000-8549999    blocks   data differs  50000     50000

These ranges hold different data than the signed archive.
```

Equal row counts with differing data means the same heights hold different blocks — a fork point left on the losing branch.

### Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Local data matches the archive. |
| `1` | Divergence found; every divergent range is listed. |
| `2` | Unanchored — the archive was unreachable or its signature failed. |

`2` is never success. Not being able to check differs from being fine.

### Flags

| Flag | Effect |
| --- | --- |
| `--against <manifest>` | Archive `latest.json`, a snapshot manifest URL, or a local path. Required. |
| `--from-block <n>` / `--to-block <n>` | Limit the checked range. |
| `--counts` | Also compare transaction and event row counts. Slower. |
| `--semantic` | Recompute per-partition semantic digests locally and compare. The strongest check, and the slowest — full re-stream of every partition in range. |
| `--public-key <pem>` | Pin the signing key instead of fetching it. |
| `--insecure` | Compare without verifying the signature. Result is unverified. |
| `--json` | Machine-readable report on stdout. |

The default fast check compares SQL-computed range digests over identity columns (~90 s for the full mainnet chain). `--semantic` recomputes the same canonical byte encoding the archive publishes and catches divergence in payload columns (`raw_tx`, event `data`, `function_args`) that identity-only digests skip. Use it when the fast check is clean but the archive has been rebuilt or a foreign runtime is in play.

## Repair what diverges

```bash
sl repair --against <archive>            # plan
sl repair --against <archive> --apply    # write it
```

Dry-run by default. The plan names exact heights, not ranges:

```
HEIGHT   ACTION   LOCAL         ARCHIVE
-------  -------  ------------  -------
8501111  replace  0xd4deb46c6d  0xedb6ba8322
```

Every partition is hashed against the digest the signed manifest declares before a single row is read from it. One transaction per partition, so an interrupted repair leaves no half-corrected range.

<Callout type="warning" title="Heights the archive doesn't have">

Local heights absent from the archive are reported, never deleted — transactions and events reference them.

</Callout>

Decoded rows are not rebuilt. Re-run your decoders for repaired ranges.

## Restore a fresh instance

```bash
sl bootstrap --against <archive>
```

Shows both timings before it starts, then restores and verifies itself:

```
coverage   genesis → 8,745,422
signature  verified

  sync from genesis    ~19.4 days (estimate)
  restore from archive ~2.3 hours
```

Refuses a database that already holds blocks — use `sl repair` for an existing instance. `--to-block <n>` stops early; `-y` skips the prompt.

## What the archive is

Immutable, digest-addressed Parquet partitions on R2, published from a repeatable-read snapshot of a production Stacks index. Three datasets — blocks, transactions, events — partitioned by height.

| Object | Contents |
| --- | --- |
| `latest.json` | Signed pointer at the current snapshot. Start here. |
| `snapshots/<digest>.json` | Signed manifest: coverage, counts, per-object digests, finality rule, audit. |
| `blocks/`, `transactions/`, `events/` | Range-partitioned Parquet, digest in the filename. |
| `attestations/<digest>/node.json` | Signed independent node audit for that snapshot: per-height matches, mismatches, and datasets a stacks-node cannot cover on its own. Present only for snapshots whose ranges have been node-attested. |

Historical partitions never change, so publishing is append-only. Every partition carries a SHA-256 over its Parquet bytes and a semantic-v1 digest (`sha256:semantic-v1`) over its canonical byte encoding, both listed in the manifest under `partitions[]` and `partition_semantic_digests[]`. The byte digest proves capture fidelity to one source; the semantic digest is what an independently-run node (or a foreign runtime speaking the same spec) computes to prove it observed the same chain. The manifest itself is ed25519-signed.

## Assurance levels

| Level | Means |
| --- | --- |
| `db-reconstructive` | Exports from one repeatable-read snapshot restore deterministically. Does not prove no historical callback was omitted. |
| `node-attested` | Block identities (`hash`, `index_block_hash`) also match an independently synced stacks-node for the covered range. Transactions and events remain `db-reconstructive` — the node does not expose execution `raw_result` or events. |
| `observer-attested` | Digests match independently retained raw observer history. |

The manifest states its level per range. Today's archive is `db-reconstructive`.

The archive is a best-effort public utility, not a hosted service. Verification is free and always will be.

</Callout>
