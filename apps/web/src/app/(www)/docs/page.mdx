# Introduction

Decoded Stacks chain data, backfilled from genesis, reorg-safe and kept current. Trust, and [verify it yourself](/docs/verification).

## Where do you start?

<Fork question="Do you already have an API layer?" name="api-layer">
<ForkPath value="index" label="Yes, I run one">

```ts index.ts
import { Index } from "@secondlayer/sdk";

await new Index().events.consume({
  eventType: "ft_transfer",
  fromCursor: await db.loadCheckpoint(),
  // !callout[/onBatch/] Write rows and the cursor in one transaction.
  onBatch: async (events, envelope, ctx) => {
    await db.commit(events, ctx.cursor);
    return ctx.cursor;
  },
  // !callout[/onReorg/] Delete from the fork height, inclusive.
  onReorg: (reorg) => db.deleteFromHeight(reorg.fork_point_height),
});
```

You keep your schema and serve it however you already do. [Index →](/docs/index)

</ForkPath>
<ForkPath value="subgraphs" label="No">

```ts subgraph.config.ts
import { defineSubgraph } from "@secondlayer/subgraphs";

export default defineSubgraph({
  name: "sbtc-flows",
  // !callout[/startBlock/] The first deploy backfills from here.
  startBlock: 8000000,
  sources: { transfers: { type: "ft_transfer", assetIdentifier: "SM3VDXK3WZZSA84XXFKAFAF15NNZX32CTSG82JFQ4.sbtc-token::sbtc-token" } },
  schema: { transfers: { columns: { amount: { type: "uint" }, sender: { type: "principal" } } } },
  handlers: {
    // !callout[/insert/] One write per event; REST serves the table.
    transfers: (event, ctx) => ctx.insert("transfers", { amount: event.amount, sender: event.sender }),
  },
});
```

You get a REST API you didn't write. That's the point, and the tradeoff. [Subgraphs →](/docs/subgraphs)

</ForkPath>
<ForkPath value="streams" label="I decode it myself">

```ts indexer.ts
await sl.streams.events.consume({
  types: ["ft_transfer"],
  fromCursor: await db.loadCheckpoint(),
  onBatch: async (events, envelope, ctx) => {
    // !callout[/insertEvents/] Raw, signed frames; you decode.
    await db.insertEvents(events, ctx.cursor);
    return ctx.cursor;
  },
  // !callout[/onReorg/] Rewinds to the fork point and re-delivers.
  onReorg: (reorg) => db.deleteFromHeight(reorg.fork_point_height),
});
```

You decode it. This is what Index is built on. [Streams →](/docs/streams)

## Get started

Install the CLI, set your key, create a subgraph from a contract, deploy it, read its rows, then check the block they came from. Keys come from [/account/keys](/account/keys). Using an agent? `bunx skills add ryanwaits/secondlayer --skill secondlayer -y`

<QuickstartPanel />

Set a `startBlock` before you deploy: the event and transaction rows it reads bill. Reads of your own tables are free.

Prefer your own box? [Self-host](/docs/self-host) is the same product on your Postgres.

export const agent = `

- After deploying, 'secondlayer verify block <height>' proves a block against Bitcoin from the checkpoint in the CLI.
- Scaffold subgraphs with 'secondlayer subgraphs scaffold' so the module package and dependencies are prepared.
`;
