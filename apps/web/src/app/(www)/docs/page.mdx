# The hosted indexer for Stacks

Curl `/v1` for decoded Stacks data right now; deploy a one-file subgraph for your own tables with the same public API; attach a webhook to either.

## Which API?

| You want | Use | What you run |
| --- | --- | --- |
| Answers from chain data right now | **Index** | We run the indexer and decoder; one keyless curl returns decoded JSON with a resume cursor, the chain tip, and overlapping `reorgs[]`. |
| Your app's own index | **Index** | `walk()` follows cursors, `from_height=0` backfills history, `reorgs[]` says which rows to roll back, `sl index codegen` emits your mirror schema. You bring the database. |
| Your own tables with zero ops | **Subgraphs** | One TypeScript file → hosted Postgres tables behind the same `/v1` API. REST, not GraphQL. The Index loop above, hosted. |
| To build from the raw inputs | **Streams** | Signed raw event firehose: bulk dumps, replay, checkpointed consumer with automatic reorg rewind. What Index itself runs on. |
