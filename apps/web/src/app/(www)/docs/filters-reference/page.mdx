# `@secondlayer/stacks/filters`

One spelling for a chain event filter. `on.ftTransfer(...)` builds it once, then projects it to Index params, Streams params, a webhook trigger or a subgraph source. The [SDK guide](/docs/sdk) has the walkthrough.
