# Listen for Stacks contract events

A contract announces what happened by printing an event. A webhook posts each print to a URL you run, as the block lands. One key, one call:

<CodeTabs sync="lang">

```bash
curl -X POST "$SECONDLAYER_API_URL/api/webhooks" \
  -H "Authorization: Bearer sk-sl_…" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "sbtc-withdrawals",
    "url": "https://my-app.com/webhooks/sbtc",
    "triggers": [{
      "type": "print_event",
      "contractId": "SM3VDXK3WZZSA84XXFKAFAF15NNZX32CTSG82JFQ4.sbtc-registry",
      "topic": "withdrawal-create"
    }]
  }'
```

```ts
import { SecondLayer, trigger } from "@secondlayer/sdk";

const sl = new SecondLayer({ apiKey: process.env.SECONDLAYER_API_KEY });

const { webhook, signingSecret } = await sl.webhooks.create({
  name: "sbtc-withdrawals",
  url: "https://my-app.com/webhooks/sbtc",
  triggers: [
    trigger.printEvent({
      contractId: "SM3VDXK3WZZSA84XXFKAFAF15NNZX32CTSG82JFQ4.sbtc-registry",
      topic: "withdrawal-create",
    }),
  ],
});
```

The signing secret comes back once, so store it. Every delivery carries a signature you check with it: [Verify the signature](/docs/webhooks#verify-the-signature).

## Narrow it

The trigger above matches one print topic. Match other prints, or other events:

| To match | Use |
| --- | --- |
| Other keys in the print | `where` ([Print fields](/docs/webhooks#print-fields)) |
| Calls instead of prints | `trigger.contractCall` ([Triggers](/docs/webhooks#triggers)) |

## Read a delivery

Each delivery is one signed POST. The print arrives as `data.event.data.value`, already parsed from Clarity: [Event shapes](/docs/webhooks#event-shapes).

## Start and catch up

A webhook starts at the chain tip and never backfills. To re-deliver a block range over it, [replay](/docs/webhooks#replay). To read past prints once and resume from a block, page [Streams](/docs/streams#read-it-directly) with a cursor.

Hosted webhooks run on your stack, $5 a month at the minimum ([What it costs](/docs/authentication#what-it-costs)). Full request and response: [Create a webhook](/docs/api/webhooks#create-webhook).
