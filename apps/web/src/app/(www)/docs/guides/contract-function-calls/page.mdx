# List every call to a Stacks contract function

Every contract call is decoded and indexed, so one function's history is a filtered read. Each row carries its arguments already parsed from Clarity. One key, one call:

<CodeTabs sync="lang">

```bash
curl "$SECONDLAYER_API_URL/v1/index/contract-calls?contract_id=SM3VDXK3WZZSA84XXFKAFAF15NNZX32CTSG82JFQ4.sbtc-token&function_name=transfer&from_height=9340000&limit=1" \
  -H "Authorization: Bearer sk-sl_…"
```

```ts
import { Index } from "@secondlayer/sdk";

const index = new Index();

const page = await index.contractCalls.list({
  contractId: "SM3VDXK3WZZSA84XXFKAFAF15NNZX32CTSG82JFQ4.sbtc-token",
  functionName: "transfer",
  fromHeight: 9340000,
  limit: 1,
});
```

`args` holds the call's arguments in order, one entry per parameter, as plain JSON. Read the order and names from the contract's ABI: `transfer` takes the amount, sender, recipient, then an optional memo.

## Narrow it

A read with no `from_height` or cursor covers only the most recent ~17,280 blocks, so pass a start to go further back.

| Narrow by | Param |
| --- | --- |
| One function | `functionName` |
| Who called it | `sender` |
| Several contracts | `contractId` as a list (max 20) |
| Every contract of a standard | `trait`, instead of `contractId` |
| A block range | `fromHeight`, `toHeight` |

- There is no `status` filter: failed calls come back too, so check each row's `status`.
- Only calls a transaction makes directly are listed.
- Reads run oldest first; there is no `order` parameter on this feed.

## Page through it

Pass the last `next_cursor` back as the next cursor. It comes back null only on an empty page, which ends the loop.

```ts
let cursor: string | null = null;
do {
  const page = await index.contractCalls.list({
    contractId,
    functionName: "transfer",
    fromHeight: cursor ? undefined : 0,
    cursor,
    limit: 1000,
  });
  for (const call of page.contract_calls) await save(call);
  cursor = page.next_cursor;
} while (cursor);
```

Pass a start height or a cursor, never both: drop the height once you hold a cursor. For a one-off export, `walk()` does the paging for you; it keeps no checkpoint ([list, walk, consume](/docs/index#list-walk-consume)).

## Tradeoff

Hosted reads are metered, with a free monthly allowance ([What it costs](/docs/authentication#what-it-costs)). A busy function means many rows, so narrow by height before you page.

Every filter and the response schema: [Decoded contract-call transactions](/docs/api/index#list-contract-calls). The decoded feeds are described in [Index](/docs/index).
