# Decode Clarity print events

You don't decode them: every print is indexed already parsed from Clarity into JSON, with the raw hex kept beside it. One key, one call:

<CodeTabs sync="lang">

```bash
curl "$SECONDLAYER_API_URL/v1/index/events?event_type=print&contract_id=SM3VDXK3WZZSA84XXFKAFAF15NNZX32CTSG82JFQ4.sbtc-registry&order=desc&limit=1" \
  -H "Authorization: Bearer sk-sl_…"
```

```ts
import { Index } from "@secondlayer/sdk";

const index = new Index();

const page = await index.events.list({
  eventType: "print",
  contractId: "SM3VDXK3WZZSA84XXFKAFAF15NNZX32CTSG82JFQ4.sbtc-registry",
  order: "desc",
  limit: 1,
});
```

The decoded tuple is `value`: uints are decimal strings, buffers are hex, principals are strings. `raw_value` is the hex you started from, kept so you can check the decode.

## See each topic's fields

A contract prints different shapes under different topics. The print-schema call lists a contract's topics and each field's Clarity and TypeScript type.

<CodeTabs sync="lang">

```bash
curl "$SECONDLAYER_API_URL/v1/index/contracts/SM3VDXK3WZZSA84XXFKAFAF15NNZX32CTSG82JFQ4.sbtc-registry/print-schema" \
  -H "Authorization: Bearer sk-sl_…"
```

```ts
const schema = await index.printSchema(
  "SM3VDXK3WZZSA84XXFKAFAF15NNZX32CTSG82JFQ4.sbtc-registry",
);
```

</CodeTabs>

Fields come back with their Clarity type, so you know `recipient` is a tuple before you parse it. The schema is sampled from indexed prints, so `sampled: true` means older topics may be missing.

## Pick out one topic

The events feed filters by contract, not by topic. Keep the topic you want from the tuple's own `topic` key.

```ts
const withdrawals = page.events.filter(
  (event) => event.payload.value?.topic === "withdrawal-create",
);
```

- Prints that aren't tuples have no `topic` key; the schema lists them under `*`.
- To be pushed one topic instead of reading it, a webhook trigger takes `topic` ([Print fields](/docs/webhooks#print-fields)).
- Page with `next_cursor`, as in [any decoded feed](/docs/index#list-walk-consume).

## Tradeoff

Hosted reads are metered, with a free monthly allowance ([What it costs](/docs/authentication#what-it-costs)). Reading a contract's prints means reading every topic it emits, so a chatty contract costs more rows than the topic you keep.

Every filter and the response schema: [Decoded events by event_type](/docs/api/index#list-events) and [Print payload schemas](/docs/api/index#get-print-schema). The shapes by contract: [Print schemas](/docs/index#print-schemas).
