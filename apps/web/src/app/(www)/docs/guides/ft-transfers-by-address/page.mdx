# Get every FT transfer for a Stacks address

Fungible-token transfers are decoded and indexed, so an address's history is a filtered read. A transfer has a sender and a recipient, so you read each side with its own call. One key, one call; here is the received side:

<CodeTabs sync="lang">

```bash
curl "$SECONDLAYER_API_URL/v1/index/ft-transfers?recipient=SP3F3GBGAR8781BF831JT4W7J5DR12ZB15A575DEC&limit=1" \
  -H "Authorization: Bearer sk-sl_…"
```

```ts
import { Index } from "@secondlayer/sdk";

const index = new Index();

const page = await index.ftTransfers.list({
  recipient: "SP3F3GBGAR8781BF831JT4W7J5DR12ZB15A575DEC",
  limit: 1,
});
```

## Both sides

There is no single address filter: each side of a transfer is filtered on its own, so make one call per side.

```ts
const [received, sent] = await Promise.all([
  index.ftTransfers.list({ recipient: address }),
  index.ftTransfers.list({ sender: address }),
]);
```

- Merge the two lists by `block_height`.
- A transfer to yourself is in both, so drop repeats by `cursor`.

A read with no `fromHeight` or cursor covers only the most recent ~17,280 blocks, so pass a start to go further back.

| Narrow by | Param |
| --- | --- |
| One token | `contractId` or `assetIdentifier` |
| A block range | `fromHeight`, `toHeight` |
| Newest first | `order: "desc"` |

`amount` is a string, in the token's smallest unit.

## Page through it

Pass the last `next_cursor` back as the next cursor. It comes back null only on an empty page, which ends the loop.

```ts
import type { FtTransfersEnvelope } from "@secondlayer/sdk";

let cursor: string | null = null;
do {
  const page: FtTransfersEnvelope = await index.ftTransfers.list({
    recipient: address,
    fromHeight: cursor ? undefined : 0,
    cursor,
    limit: 1000,
  });
  for (const transfer of page.events) await save(transfer);
  cursor = page.next_cursor;
} while (cursor);
```

Pass a start height or a cursor, never both: drop the height once you hold a cursor. A cursor only resumes under the order that issued it. For a one-off export, `walk()` does the paging for you; it keeps no checkpoint ([list, walk, consume](/docs/index#list-walk-consume)).

## Tradeoff

Hosted reads are metered, with a free monthly allowance ([What it costs](/docs/authentication#what-it-costs)). Request `fields` to trim each row.

Every filter and the response schema: [List FT transfers](/docs/api/index#list-ft-transfers). The decoded feeds are described in [Index](/docs/index).
