# Get NFT transfers for a Stacks collection

Every NFT transfer is decoded and indexed, so one collection's history is a filtered read. Each row names the token, its sender and its recipient. One key, one call:

<CodeTabs sync="lang">

```bash
curl "$SECONDLAYER_API_URL/v1/index/nft-transfers?contract_id=SP2N959SER36FZ5QT1CX9BR63W3E8X35WQCMBYYWC.leo-cats&order=desc&limit=1" \
  -H "Authorization: Bearer sk-sl_…"
```

```ts
import { Index } from "@secondlayer/sdk";

const index = new Index();

const page = await index.nftTransfers.list({
  contractId: "SP2N959SER36FZ5QT1CX9BR63W3E8X35WQCMBYYWC.leo-cats",
  order: "desc",
  limit: 1,
});
```

`value` is the token id as a serialized Clarity value in hex, not a plain number. A collection's ids are usually `uint`, which decodes to the number you know from the marketplace.

## Read the token id

Decode `value` with `@secondlayer/stacks`; the row above is token 2028.

```ts
import { cvToValue, deserializeCV } from "@secondlayer/stacks/clarity";

const value = "0x01000000000000000000000000000007ec"; // a row's value

const tokenId = cvToValue(deserializeCV(value)); // 2028n
```

## Narrow it

A read with no `fromHeight` or cursor covers only the most recent ~17,280 blocks, so pass a start to go further back.

| Narrow by | Param |
| --- | --- |
| One collection | `contractId` |
| One NFT type in a contract | `assetIdentifier` |
| Who sent it, who received it | `sender`, `recipient` |
| A block range | `fromHeight`, `toHeight` |
| Newest first | `order: "desc"` |

- `contractId` is one contract. A contract that defines several NFT types needs `assetIdentifier` to pick one.
- There is no token id filter: to follow one token, filter on the decoded id after the read.
- Mints and burns are separate feeds, not transfers ([Index](/docs/index)).

## Page through it

Pass the last `next_cursor` back as the next cursor. It comes back null only on an empty page, which ends the loop.

```ts
import type { NftTransfersEnvelope } from "@secondlayer/sdk";

let cursor: string | null = null;
do {
  const page: NftTransfersEnvelope = await index.nftTransfers.list({
    contractId,
    fromHeight: cursor ? undefined : 0,
    cursor,
    limit: 1000,
  });
  for (const transfer of page.events) await save(transfer);
  cursor = page.next_cursor;
} while (cursor);
```

Pass a start height or a cursor, never both: drop the height once you hold a cursor. A cursor only resumes under the order that issued it. For a one-off export, `walk()` does the paging for you; it keeps no checkpoint ([list, walk, consume](/docs/index#list-walk-consume)).

## Tradeoff

Hosted reads are metered, with a free monthly allowance ([What it costs](/docs/authentication#what-it-costs)). A popular collection means many rows, so narrow by height before you page, and request `fields` to trim each row.

Every filter and the response schema: [List NFT transfers](/docs/api/index#list-nft-transfers). The decoded feeds are described in [Index](/docs/index).
