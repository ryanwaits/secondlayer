# Instance token & archive credits

Your instance has one token, not accounts. Loopback reads need no key; writes and bind-beyond-loopback use the `INSTANCE_TOKEN` from `secondlayer init`. Archive restore and backfill are a separate card credit.

| Surface | Key | Behavior |
| --- | --- | --- |
| Index / Streams / subgraphs on `127.0.0.1` | None | Local instance, free and unlimited |
| Writes (`subgraphs deploy`, subscriptions) | `INSTANCE_TOKEN` | From `secondlayer init` |
| [Archive](/docs/archive) bootstrap / backfill | Card credits | `secondlayer credits buy` |

```bash
# Local read — no key
curl http://127.0.0.1:3800/v1/index/events?limit=5

# Write — instance token
curl http://127.0.0.1:3800/v1/streams/tip \
  -H "Authorization: Bearer $INSTANCE_TOKEN"
```

The CLI and MCP read `INSTANCE_TOKEN` (`SL_API_KEY` is a legacy alias). The SDK takes it explicitly: `new SecondLayer({ apiKey: process.env.INSTANCE_TOKEN })`. Default `baseUrl` is `http://127.0.0.1:3800` (`SL_API_URL` overrides).

## Archive credits

Bootstrap, backfill, and reindex from the [signed public archive](/docs/archive) are metered per unit; verification is free. Packs are $10, $25, $50, or $100. The prepaid balance is the hard cap.

```bash
secondlayer credits buy --email you@example.com --pack 25
secondlayer credits balance
```

`credits buy` opens a one-time card checkout against [archive.secondlayer.tools](https://archive.secondlayer.tools) — no account, no login.

Auto-refill is off until you set it: `secondlayer credits refill --below 5 --pack 25`.

## Webhook signing secrets

A **signing secret** (`whsec_…`) is per-subscription and verifies an incoming webhook came from your instance (`verifyWebhookSignature`) — see [Subscriptions](/docs/subscriptions). Never in `Authorization`. Rotate with `secondlayer subscriptions rotate-secret`.
