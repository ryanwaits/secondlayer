# Instance token and account key

Two credentials. The instance token opens your box. The account key identifies you on the hosted API and the archive.

## Your instance

| Surface | Credential | Behavior |
| --- | --- | --- |
| `/v1` on `127.0.0.1` | none | your Postgres, no meter |
| `/v1` past loopback | `INSTANCE_TOKEN` | same header on Index, Streams, subgraphs |
| Writes (`/api/subgraphs`, webhooks, node) | `INSTANCE_TOKEN` | loopback included |

`secondlayer init` writes `INSTANCE_TOKEN`. Send `Authorization: Bearer $INSTANCE_TOKEN`.

```bash
# Local read — no key
curl http://127.0.0.1:3800/v1/index/events?limit=5

# Write — instance token, from 127.0.0.1 too
curl -X POST http://127.0.0.1:3800/api/subgraphs/my-balances/reindex \
  -H "Authorization: Bearer $INSTANCE_TOKEN"
```

Loopback is the publish spec (`API_PUBLISH_ADDR`), not the caller's address. On a keyless OSS read, a wrong key is ignored; a matching token is used.

## Hosted API and archive

| Surface | Credential | Behavior |
| --- | --- | --- |
| `api.secondlayer.tools` `/v1` Index, Streams | `SECONDLAYER_API_KEY` (`sk-sl_*`) | required. Same prepaid credits as archive. Subgraphs and webhooks run on your instance, not here |
| Archive quote / fetch / credits | `SECONDLAYER_API_KEY` or `secondlayer login --credits` | required |

Never put `sk-sl_*` in `INSTANCE_TOKEN`. Never put the hex token in `SECONDLAYER_API_KEY`.

Get a key: [sign in](https://www.secondlayer.tools/login) with your email. Your first key is shown once on [your account page](https://www.secondlayer.tools/account), where you can create more.

Hosted reads, live or history, priced the same:

| Rows delivered | Cost |
| --- | --- |
| First 10M rows per account per month | free |
| Past 10M rows/month | $5 per 1M rows, $2 per 1M past $50 in a month |
| `304` on `If-None-Match` for a finalized page | free |

The SDK sends `If-None-Match` for you. Its cache holds the last 64 pages in memory; pass `etagCache` to keep one across runs.

Past the free monthly allowance, a key with no balance gets a `402` (`insufficient_credits`) with a top-up link, before anything is served. A key still under the allowance, or with a balance, reads normally and is billed per row after the response.

## Archive credits

Bootstrap, backfill, and reindex from the [signed public archive](/docs/archive) draw credits per partition bundle fetched; verification is always free. `bootstrap` and `repair` show the price against your balance before anything is charged. Every partition arrives over a short-lived presigned URL and is digest-checked before a row is written. Your first six repair bundles each month are free. Packs are $10, $25, $50, or $100. The prepaid balance is the hard cap.

```bash
secondlayer credits buy --email you@example.com --pack 25
secondlayer credits balance
```

`credits buy` opens a one-time card checkout against [archive.secondlayer.tools](https://archive.secondlayer.tools). `credits balance` and metered bootstrap need the account key or `secondlayer login --credits`.

Auto-refill is off until you set it: `secondlayer credits refill --below 5 --pack 25`.

## Webhook signing secrets

A **signing secret** (`whsec_…`) is per-webhook and verifies an incoming webhook came from your instance (`verifyWebhookSignature`); see [Webhooks](/docs/webhooks). Never in `Authorization`. Rotate with `secondlayer webhooks rotate-secret`.
