# Authentication

Reads are public during the open beta. API keys gate writes and scope which surfaces a key can read.

| Surface | Key needed | Behavior |
| --- | --- | --- |
| Index reads (`/v1/index/*`) | None | Anonymous-readable; contracts fully open |
| Public subgraphs (`/v1/subgraphs`) | None | Managed deploys default public, anon-readable |
| Private / BYO subgraphs (`/v1/subgraphs`) | Owner's `sk-sl_` key | Anon requests `404` |
| Dashboard (`/api/subgraphs`) | Session or key | Always requires auth |
| Streams firehose + all writes | Key | Deploy / publish / subscriptions all keyed |

Free and anonymous reads cover the recent 24-hour window; older history needs [pay-as-you-go credits](#pay-as-you-go-credits) or a plan, and a read below the window returns `402 UPGRADE_REQUIRED`.

<Callout type="note" title="Pay per call instead">

Keyless reads and `POST /v1/subgraphs` also accept an [x402 payment](/docs/x402) — no account at all.

</Callout>

```bash
# Public read — no key
curl https://api.secondlayer.tools/v1/index/events?limit=5

# Keyed request — bearer token
curl https://api.secondlayer.tools/v1/streams/tip \
  -H "Authorization: Bearer $SL_API_KEY"
```

## API keys

A key looks like `sk-sl_…`. The CLI and MCP server read `SL_API_KEY` automatically; the SDK takes it explicitly: `new SecondLayer({ apiKey: process.env.SL_API_KEY })`.

| Product | Reads | Can mint new keys? | Tier | Use it as |
| --- | --- | --- | --- | --- |
| `account` | Streams **and** Index | Yes | your account plan | your **owner** key |
| `streams` | Streams only | No (`403`) | inherits your plan | a scoped key |
| `index` | Index only | No (`403`) | inherits your plan | a scoped key |

Tiers (`free` · `build` · `scale` · `enterprise`) set rate limit and, for Streams, history retention. Free reads Index and Streams at 10 req/s, never slower than anonymous.

Keep keys server-side. Rotate or revoke in the [platform console](https://app.secondlayer.tools/platform/api-keys).

## Creating a key

Console keys default to `account`. Mint a **scoped** key for agents and CI with an `account` key — minted keys are never `account`, never a higher tier than your plan.

```bash
curl -X POST https://api.secondlayer.tools/v1/api-keys \
  -H "Authorization: Bearer $OWNER_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "product": "streams", "name": "ci" }'
# → 201 { "key": "sk-sl_…", "product": "streams", "tier": null, ... }
```

The plaintext `key` is returned **once**. Same mint elsewhere: `sl.apiKeys.create({ product })` (SDK), `sl keys create --product streams` (CLI), `account_create_key` (MCP).

### No account yet?

`POST https://api.secondlayer.tools/v1/keys` with no `Authorization` header mints a read-only free-tier **ghost key**, capped at 3 mints per IP per day: `201 { "key": "sk-sl_…", "tier": "free", "scopes": ["streams:read", "index:read"], "claim_url": "…" }`.

<Callout type="note">

Every non-GET returns `403 GHOST_KEY_READ_ONLY` until you claim the account via `claim_url`. Distinct from the owner-key mint at `/v1/api-keys` above.

</Callout>

## Pay-as-you-go credits

Top up prepaid credits with a card — packs of $10, $25, $50, or $100 via `POST /api/billing/topup`. A positive balance reads beyond the free window, unthrottled, debited **$5 per 1,000,000 rows** (5 USD-micros per row) across Index and Streams from one shared balance. The balance is the hard cap: spent, reads fall back to the free window. Credits cover reads, not writes — a subgraph deploy or a webhook still needs a paid plan or the 14-day trial.

## Session tokens

`sl login` issues a **session token** (`ss-sl_…`) instead of a long-lived key; the server extends its expiry on each use. One session is shared by the SDK, CLI, and MCP server. Prefer it for interactive CLI use; reserve `sk-sl_` keys for servers and agents.

## Webhook signing secrets

A **signing secret** (`whsec_…`) is per-subscription and verifies an incoming webhook came from Secondlayer (`verifyWebhookSignature`) — see [Subscriptions](/docs/subscriptions). Never in `Authorization`. Rotate with `sl subscriptions rotate-secret`.
