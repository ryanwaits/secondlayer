# Authentication

Loopback reads need no key. Writes and bind-beyond-loopback use the instance token from `sl init`. Archive restore and backfill are a separate card credit.

| Surface | Key | Behavior |
| --- | --- | --- |
| Index / Streams / public subgraphs on `127.0.0.1` | None | Local instance |
| Writes (`subgraphs deploy`, subscriptions) | `INSTANCE_TOKEN` | From `sl init` |
| Official-archive bootstrap / R2 backfill | Card credits | [Buy](/#history) or `sl credits buy` |

```bash
# Local read — no key
curl http://127.0.0.1:3800/v1/index/events?limit=5

# Write — instance token
curl http://127.0.0.1:3800/v1/streams/tip \
  -H "Authorization: Bearer $INSTANCE_TOKEN"
```

The CLI and MCP read `SL_API_KEY` / `INSTANCE_TOKEN`. The SDK takes it explicitly: `new SecondLayer({ apiKey: process.env.INSTANCE_TOKEN })`. Default `baseUrl` is `http://127.0.0.1:3800`.

## Archive credits

Large restore and backfill off our R2 is metered. Packs are $10, $25, $50, or $100. The prepaid balance is the hard cap.

```bash
sl credits buy --email you@example.com --pack 25
SL_API_URL=https://api.secondlayer.tools sl login
sl credits balance
```

Auto-refill is off until you set it: `sl credits refill --below 5 --pack 25`.

## Webhook signing secrets

A **signing secret** (`whsec_…`) is per-subscription and verifies an incoming webhook came from your instance (`verifyWebhookSignature`) — see [Subscriptions](/docs/subscriptions). Never in `Authorization`. Rotate with `sl subscriptions rotate-secret`.
