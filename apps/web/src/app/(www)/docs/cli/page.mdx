# CLI

The `sl` command-line tool: init a local runtime, bootstrap history, deploy subgraphs, attach webhooks.

## Install

```bash
bun add -g @secondlayer/cli
```

## Common commands

```bash
sl init --network mainnet
sl start --print
sl bootstrap --against <manifest>
sl observer
sl subgraphs create --from-contract <id>
sl subgraphs deploy
sl subgraphs list
sl subscriptions create
sl context
sl verify all --against <manifest>
sl repair --against <archive>
sl credits buy --email you@example.com --pack 25
sl credits balance
```

[Verified archive](/docs/archive) owns `sl verify` / `sl repair`. [Self-host](/docs/self-host) is the compose loop.

<Callout type="note" title="Chain subscriptions use a different surface">

[Direct chain subscriptions](/docs/subscriptions#direct-chain-subscriptions-no-subgraph) go through the SDK, REST, or MCP. They take a `triggers` array, not a table.

</Callout>

## Local runtime

Write keys, restore history, print the observer stanza.

```bash
sl init --network mainnet
sl bootstrap --against https://archive.secondlayer.tools/.../snapshots/<digest>.json
sl observer --mode indexer
```

| Command | Flag | Default | Notes |
| --- | --- | --- | --- |
| `sl init` | `--network` | `STACKS_NETWORK` or `mainnet` | `mainnet`, `testnet`, or `devnet` |
| | `--api-url` | `http://127.0.0.1:3800` | Local API |
| | `--force` | off | Overwrite generated values in `.env.local` |
| `sl bootstrap` | `--against` | required | Manifest URL or file |
| | `--to-block` | archive tip | Stop early |
| | `--public-key` | resolved | Pin the signing key |
| | `-y, --yes` | off | Skip confirm |
| | `--json` | off | Machine output |
| `sl observer` | `--mode` | `indexer` | `indexer` retries; `signer-shared` does not |
| | `--endpoint` | `indexer:3700` (`127.0.0.1:3700` on devnet) | `host:port` only — no URL |
| | `--recovery` | required for signer-shared | `journal` or `archive` |
| | `--network` | `STACKS_NETWORK` or `mainnet` | Loopback refused except devnet |

`sl bootstrap` refuses a non-empty database. Fix an existing instance with [`sl repair`](/docs/archive). Exit `0` restored, `1` diverged, `2` refused.

`sl verify [target]` compares local data to a signed archive. Target is `all`, `raw` (default), `decode:<name>`, or `subgraph:<name>`. `--quick` is identity; `--deep` is semantic; `--anchor` requires a verified signature. Flags live on [Verified archive](/docs/archive#flags).

<Callout type="note" title="Signer-shared nodes skip retries">

`--mode signer-shared` requires `--recovery journal` or `--recovery archive`. Missed blocks refill from that source.

</Callout>

## Scaffold from a contract

```bash
sl subgraphs create sbtc-registry \
  --from-contract SM3VDXK3WZZSA84XXFKAFAF15NNZX32CTSG82JFQ4.sbtc-registry
```

Infers each print topic's payload from indexed history — see [print schemas](/docs/index#print-schemas). Anonymous. `--table-per-topic` emits one table per topic.

`sl subgraphs codegen <file> --payloads` emits a `.d.ts` next to the definition. Incompatible with `--target` / `--models-only` / `--env`. Deploy `warnings` on unobserved `event.data` fields are advisory.

<Callout type="warning" title="Commit your definition before deploying">

`sl subgraphs deploy` checks the source file is committed. An uncommitted deploy leaves the only copy in the database.

A terminal prompts. Scripts and CI fail. `--allow-uncommitted` overrides and logs the skip. Outside a git repo, and `--dry-run`, skip the check.

</Callout>

## Generate typed contract clients

Turn Clarity contracts into typed TypeScript — local `.clar` files, deployed contracts, or a Clarinet project.

```bash
sl contracts generate ./contracts/token.clar -o ./src/generated.ts
sl contracts generate SP3K8BC0PPEVCV7NZ6QSRWPQ2JE9E5B6N3PA0KBR9.alex-vault -o ./src/generated.ts
sl contracts generate --watch    # regenerate on .clar / config / Clarinet.toml changes
```

Deployed contract ids fetch the ABI (address prefix picks the network). Config-driven projects regenerate with `sl contracts generate`:

```ts
// secondlayer.config.ts
import { defineConfig } from "@secondlayer/cli";
import { clarinet, react } from "@secondlayer/cli/plugins";

export default defineConfig({
  out: "./src/generated/contracts.ts",
  plugins: [clarinet(), react()],
});
```

| Plugin | What it adds |
|---|---|
| `clarinet()` | Real ABIs from your Clarinet project via Simnet — typed clients for `[project.requirements]` dependency contracts too (`includeRequirements: false` to opt out) |
| `react()` | Typed React hooks per contract |
| `testing()` | Clarinet SDK test helpers |

Named aliases per function (`TokenTransferArgs`) plus a `TypedAbi` const. Feed it to `getContract` from [`@secondlayer/stacks`](/docs/stacks#also-in-the-box).

## Frozen features

These work but get no further investment.

- `sl subgraphs codegen --target prisma|drizzle|kysely` — BYO ORM schema. See [Subgraphs](/docs/subgraphs#use-your-own-database--orm).
- `sl subgraphs publish` / `unpublish` are hidden. Visibility is on [Subgraphs](/docs/subgraphs#visibility--publishing) and deploy `--visibility`.
- `sl local` — superseded by [`sl devnet`](/docs/devnet). Hidden.
