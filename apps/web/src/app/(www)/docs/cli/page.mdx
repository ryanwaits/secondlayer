# CLI

Deploy subgraphs and webhooks hosted or on your own box, and run the instance, from one terminal.

## Install

```bash
bun add -g @secondlayer/cli
```

The binary is `secondlayer`. `sl` is a short alias.

### Command map

Every top-level `secondlayer` command, with the page that owns it.

| Command | What it does | Docs |
| --- | --- | --- |
| `init` | Write the instance token and keys to `.env.local` | [Local runtime](#local-runtime) |
| `bootstrap` | Restore chain history from a verified archive | [Local runtime](#local-runtime) |
| `observer` | Print the node's `events_observer` stanza | [Self-host](/docs/self-host#connect-your-node) |
| `login` / `logout` | Sign in through your browser; `logout` signs the machine out (`--email` for an emailed code, `--with-token` to read a key from stdin) | [Keys and billing](/docs/authentication#archive-fetches) |
| `whoami` | Show the instance and account targets | [Keys and billing](/docs/authentication) |
| `keys` | List account keys and rotate one | [Keys and billing](/docs/authentication#rotate-a-key) |
| `subgraphs` | Create, deploy, query, reindex, and backfill subgraphs | [Subgraphs](/docs/subgraphs) |
| `webhooks` | Create, test, pause, replay, and inspect webhook deliveries | [Webhooks](/docs/webhooks) |
| `streams` | Read raw chain events, tips, reorgs, and bulk dumps (`--chain bitcoin` for Runes events) | [Streams](/docs/streams) |
| `index` | Query decoded events, transfers, contract calls, blocks, and Runes (`index runes`) | [Index](/docs/index) |
| `codegen` | Generate typed contract clients, prints, and ORM schemas | [below](#generate-typed-contract-clients) |
| `devnet` | Run Secondlayer against a local Clarinet devnet | [Local chain](#local-chain) |
| `status` | Local instance health | [Local runtime](#local-runtime) |
| `doctor` | Diagnose the full stack | [Self-host](/docs/self-host) |
| `config` | Read and write CLI configuration | `secondlayer config --help` |
| `context` | Print an orientation snapshot of tips, subgraphs, webhooks, and operations | [MCP and skills](/docs/mcp) |
| `verify` | Compare local data to a signed archive; prove one block; replay a subgraph | [Verify](/docs/verification) |
| `repair` | Replace local data that diverges from a signed archive | [Verified archive](/docs/archive) |
| `archive` | Price, fetch, verify, and repair against the hosted archive | [Verified archive](/docs/archive) |
| `credits` | Buy, check, and auto-refill your credits | [Keys and billing](/docs/authentication#archive-fetches) |
| `backup` | Write a restorable bundle of the index and keys | [Self-host](/docs/self-host#backup) |
| `restore` | Restore an instance from a backup bundle | [Self-host](/docs/self-host#backup) |
| `uninstall` | Stop the stack; the index and keys survive | [Self-host](/docs/self-host#stop-it) |

- `--api-key` shape-routes hex to `INSTANCE_TOKEN` and `sk-sl_*` to `SECONDLAYER_API_KEY`.
- Instance commands refuse `api.secondlayer.tools`, except `secondlayer subgraphs` and `secondlayer webhooks`, which take `SECONDLAYER_API_KEY` against the hosted URL ([hosted subgraphs](tip "Hosted is the default path: one private stack per account, no box to run.")).
- Credentials: [Keys and billing](/docs/authentication) and [Instance token](/docs/self-host#instance-token).
- `login` prints a code and opens your browser; approve it and the CLI is signed in until `logout`. It never makes an API key; keys are for reading data and live under Keys. `login --email` asks for an emailed code instead.

<Callout type="note" title="Webhook triggers">

- `webhooks create` takes `--trigger` / `--triggers-file`.
- SDK and REST accept the same `triggers` array ([Triggers](/docs/webhooks#triggers)).

</Callout>

### Local runtime

Write keys, restore history, print the observer stanza.

```bash
secondlayer init --network mainnet
secondlayer bootstrap --against https://archive.secondlayer.tools/.../snapshots/<digest>.json
secondlayer observer --mode indexer
```

| Command | Flag | Default | Notes |
| --- | --- | --- | --- |
| `secondlayer init` | `--network` | `STACKS_NETWORK` or `mainnet` | `mainnet`, `testnet`, or `devnet` |
| | `--api-url` | the local API, port `3800` | Local API |
| | `--force` | off | Overwrite generated values in `.env.local` |
| `secondlayer status` | `--json` | off | Local instance health from `/public/status` |
| `secondlayer bootstrap` | `--against` | required | Manifest URL or file |
| | `--to-block` | archive tip | Stop early |
| | `--from-block` | genesis | Forward-only: start here, history below is out of scope |
| | `--verify` | `all` | Post-load digests: `all` or `blocks` |
| | `--public-key` | resolved | Pin the signing key |
| | `-y, --yes` | off | Skip confirm |
| | `--json` | off | Machine output |
| `secondlayer observer` | `--mode` | `indexer` | `indexer` retries; `signer-shared` does not |
| | `--endpoint` | `indexer:3700` (loopback `:3700` on devnet) | `host:port` only, no URL |
| | `--network` | `STACKS_NETWORK` or `mainnet` | Loopback refused except devnet |

- `secondlayer bootstrap` refuses a non-empty database. Fix an existing instance with [`secondlayer repair`](/docs/archive).
- Exit `0` restored, `1` diverged, `2` refused.

`secondlayer verify` has three forms:

- `secondlayer verify [target]` compares local data to a signed archive. Target is `all` or `raw` (default); the archive has no digests for `decode:<name>` or `subgraph:<name>` yet. `--quick` is identity, `--deep` is semantic, `--anchor` requires a verified signature. Flags live on [Verified archive](/docs/archive#flags).
- `secondlayer verify block <height|index_block_hash>` proves one Stacks block from the checkpoint built into the CLI, trusting nothing else. Flags `--node`, `--checkpoint`, `--rows`, `--json`; exit `0` proven, `1` a link is broken, `2` could not check. Links and output: [Verify](/docs/verification#check-a-block).
- `secondlayer verify subgraph <name> --replay` recomputes a `state` subgraph from proven blocks and compares the served rows. `--from`/`--to` narrow the range. See [Check rows](/docs/subgraphs#check-rows).

<Callout type="note" title="Signer-shared nodes skip retries">

A block the node fails to deliver stays a gap. `secondlayer repair` fetches it from the archive with [credits](/docs/authentication#archive-fetches). The full stanza: [Connect your node](/docs/self-host#connect-your-node).

</Callout>

## Scaffold from a contract

```bash
secondlayer subgraphs create sbtc-registry \
  --from-contract SM3VDXK3WZZSA84XXFKAFAF15NNZX32CTSG82JFQ4.sbtc-registry
```

Infers each print topic's payload from indexed history; see [print schemas](/docs/index#print-schemas). Anonymous. `--table-per-topic` emits one table per topic.

- `secondlayer codegen prints <file>` emits a `.d.ts` next to the definition.
- Incompatible with `--target` / `--models-only` / `--env`.
- Deploy `warnings` on unobserved `event.data` fields are advisory.

<Callout type="warning" title="Commit your definition before deploying">

`secondlayer subgraphs deploy` checks the source file is committed. An uncommitted deploy leaves the only copy in the database.

- A terminal prompts. Scripts and CI fail.
- `--allow-uncommitted` overrides and logs the skip.
- Outside a git repo, and `--dry-run`, skip the check.

</Callout>

## Generate typed contract clients

Turn Clarity contracts into typed TypeScript: local `.clar` files, deployed contracts, or a Clarinet project.

```bash
secondlayer codegen contracts ./contracts/token.clar -o ./src/generated.ts
secondlayer codegen contracts SP3K8BC0PPEVCV7NZ6QSRWPQ2JE9E5B6N3PA0KBR9.alex-vault -o ./src/generated.ts
secondlayer codegen contracts --watch    # regenerate on .clar / config / Clarinet.toml changes
```

Deployed contract ids fetch the ABI (address prefix picks the network). Config-driven projects regenerate with `secondlayer codegen contracts`:

```ts secondlayer.config.ts
import { defineConfig } from "@secondlayer/cli";

export default defineConfig({
  out: "./src/generated/contracts.ts",
  clarinet: true, // or { path, include, exclude, includeRequirements }
});
```

- `clarinet: true` loads real ABIs from your Clarinet project via Simnet, including typed clients for `[project.requirements]` dependency contracts (`includeRequirements: false` to opt out).
- It skips silently when `Clarinet.toml` is missing.

The output:

- Named aliases per function (`TokenTransferArgs`) plus a `TypedAbi` const.
- Feed it to `getContract` from [`@secondlayer/stacks`](https://stacks.secondlayer.tools).
- Clarinet tests use the [simnet transport](https://stacks.secondlayer.tools/guide/simnet).

## Local chain

Run Secondlayer against your Clarinet devnet. Streams, Index, Subgraphs and Webhooks all work locally, with no cloud and no account.

### Connect

From inside your Clarinet project:

```text ~/clarinet-project
$ secondlayer devnet connect
Secondlayer stack up
  api      → http://localhost:3800
  indexer  → http://localhost:3700

The api is published on 127.0.0.1 only: /v1 reads need no credential.
Writes (deploys, webhooks) send INSTANCE_TOKEN=dev-instance-token.
```

#### Prerequisites

- [Clarinet](https://github.com/hirosystems/clarinet) and a Clarinet project (a directory with `Clarinet.toml`).
- Docker (Docker Desktop or [OrbStack](https://orbstack.dev) on macOS).
- The CLI: <Cmd>bun add -g @secondlayer/cli</Cmd>.

#### What connect does

- Patches `settings/Devnet.toml` so the devnet node forwards events to the indexer on `:3700`.
- Writes `.secondlayer/docker-compose.yml`: Postgres plus the one-box runtime image, the same one the [self-host](/docs/self-host) compose runs.
- Pulls the image and starts both with `docker compose up -d`.
- Sets a fixed local instance token, a public dev signing key for webhooks, and an allowlist so webhooks can reach your localhost receiver.

### Start the devnet

Start the devnet; it auto-deploys your contracts and streams every block to the indexer.

```bash
clarinet devnet start
```

Services in `settings/Devnet.toml` cost memory you may not need. Set the ones you can live without to `true`:

| Key | Saves | Costs you |
| --- | --- | --- |
| `disable_stacks_explorer` | memory | the explorer UI |
| `disable_bitcoin_explorer` | memory | the Bitcoin explorer UI |
| `disable_stacks_api` | memory, `:3999` | the [faucet](#mock-sbtc) and the default `devnet` chain node URL |
| `disable_postgres` | memory, `:5432` | the Stacks API, which needs it |

### Send a call

Send calls with [@secondlayer/stacks](https://stacks.secondlayer.tools/guide/transactions), pointed at the devnet node. The `devnet` chain defaults to the Stacks API on port 3999, which is off when you disable it.

```bash
bun add @secondlayer/stacks
```

```ts call.ts
import { createWalletClient, http } from "@secondlayer/stacks";
import { privateKeyToAccount } from "@secondlayer/stacks/accounts";
import { devnet } from "@secondlayer/stacks/chains";

const client = createWalletClient({
	account: privateKeyToAccount(
		"753b7cc01a1a2e86221266a154af739463fce51219d97e4f856cd7200c3bd2a601", // devnet deployer, from settings/Devnet.toml
	),
	chain: devnet,
	transport: http("http://localhost:20443"), // the devnet node; the Stacks API on :3999 may be off
});

const txid = await client.callContract({
	contract: "ST1PQHQKV0RJXZFY1DGX8MNSNYVE3VGZJSRTPGZGM.counter",
	functionName: "increment",
	functionArgs: [],
});
console.log(txid);
```

The examples below read back a `counter` contract that prints an event on each call:

```clarity contracts/counter.clar
(define-data-var counter uint u0)
(define-public (increment)
  (let ((new-value (+ (var-get counter) u1)))
    (var-set counter new-value)
    (print {event: "incremented", value: new-value})
    (ok new-value)))
```

### Read it back

Reads need no credential: the API is published on loopback only. Run the call a few times first.

#### Subgraphs

Generate a subgraph from the prints already indexed, deploy it, then read its table. Writes carry the fixed local token, `dev-instance-token`; it is a local-dev value, not a secret.

```bash
bun add @secondlayer/subgraphs
secondlayer subgraphs create counter --from-contract ST1PQHQKV0RJXZFY1DGX8MNSNYVE3VGZJSRTPGZGM.counter
export SECONDLAYER_API_URL=http://localhost:3800
export INSTANCE_TOKEN=dev-instance-token
git add subgraphs/counter.ts
secondlayer subgraphs deploy subgraphs/counter.ts
curl "$SECONDLAYER_API_URL/v1/subgraphs/counter/counter?_limit=5"
```

```json
{
  "rows": [
    {
      "_id": "1",
      "_block_height": "69",
      "_tx_id": "0x606013dd2a02400045e1d28ab7d1d84649014e4d81063daa1cc83d45af3149ff",
      "topic": "print",
      "value": { "event": "incremented", "value": "1" }
    },
    ...
  ],
  "next_cursor": "3",
  "tip": { "block_height": "77", "subgraph_height": 77, "blocks_behind": 0 }
}
```

- `create --from-contract` needs at least one print event indexed, so send a call first.
- Deploy refuses an unstaged file. `git add` it, or pass `--allow-uncommitted`.

#### Webhooks

A webhook posts each matching event to your URL. The delivery leaves the container, so a receiver on your machine is `host.docker.internal`, not `localhost`.

```ts receiver.ts
Bun.serve({
	port: 4999,
	hostname: "0.0.0.0",
	async fetch(request) {
		console.log(
			[...request.headers.keys()].filter((key) => key.includes("signature")).join(","),
			await request.text(),
		);
		return new Response("ok");
	},
});
```

```bash
secondlayer webhooks create counter-prints -u http://host.docker.internal:4999/hook \
  --trigger '{"type":"print_event","contractId":"ST1PQHQKV0RJXZFY1DGX8MNSNYVE3VGZJSRTPGZGM.counter"}'
```

The receiver logs one line per call:

```text
webhook-signature,x-secondlayer-signature,x-secondlayer-signature-keyid {"type":"chain.print_event.apply","timestamp":"2026-11-03T17:59:56.000Z","data":{"event":{"data":{"topic":"print","value":{"event":"incremented","value":"1"},…},"type":"contract_event","tx_id":"0x606013dd…49ff","event_index":0},"action":"apply","trigger":"print_event","canonical":true,"block_height":69}}
```

Deliveries are signed with a public local dev key. Fetch the verify key from `GET /api/webhooks/signing-key` with your instance token; [Webhooks](/docs/webhooks) covers verification.

### Mock sBTC

Mint mock sBTC to an address on your devnet. It needs the Stacks API on `:3999`, so leave `disable_stacks_api` off.

```bash
secondlayer devnet faucet --to ST1PQHQKV0RJXZFY1DGX8MNSNYVE3VGZJSRTPGZGM
```

```text
  minting 1000000 sats to ST1PQHQKV0RJXZFY1DGX8MNSNYVE3VGZJSRTPGZGM
  via ST1PQHQKV0RJXZFY1DGX8MNSNYVE3VGZJSRTPGZGM.sbtc-deposit as signer ST1PQHQKV0RJXZFY1DGX8MNSNYVE3VGZJSRTPGZGM
```

| Flag | Default | Purpose |
| --- | --- | --- |
| `--to <address>` | required | Recipient Stacks address |
| `--amount <sats>` | `1000000` | Amount in sats, minimum 546 |
| `--contract <id>` | `<deployer>.sbtc-deposit` | sBTC deposit contract |

### Tear down

```bash
secondlayer devnet down            # stop the stack
secondlayer devnet down --purge    # stop and wipe the local index volumes
```

## Frozen features

These work but get no further investment.

- `secondlayer codegen subgraph --target prisma|drizzle|kysely`: typed ORM schema. See [Subgraphs](/docs/subgraphs#typed-orm-schemas-codegen).
