# Self-host

Postgres plus one Secondlayer container. You run the node, or bundle it.

## Quick start

```bash
secondlayer init --network mainnet
# Copy .env.local secrets into docker/oss/.env

cd docker/oss
docker compose up -d
secondlayer observer --mode indexer --endpoint secondlayer:3700
secondlayer bootstrap --against <manifest>
secondlayer verify all --against <manifest>
```

API: `http://127.0.0.1:3800`. Health: `curl http://localhost:3800/health`.

<Callout type="warning" title="No light mode">

No Hiro-REST backfill. Run a node, bundle one, or restore from the [archive](/docs/archive).

</Callout>

## Profiles

| Profile | What runs |
| --- | --- |
| default | `postgres` + `secondlayer` (API, ingest, decoder, subgraph, webhooks) |
| `stacks-node` | + bundled Stacks, public Bitcoin |
| `full-node` | + bundled Stacks and bitcoind |

```bash
docker compose --profile stacks-node up -d
docker compose --profile full-node up -d
```

`NODE_MODE` is `external` | `stacks` | `full`. `full` needs `BITCOIN_RPC_PASSWORD`.

## Config

Six required non-secrets. Secrets come from `secondlayer init`.

| Key | Default | Notes |
| --- | --- | --- |
| `NETWORK` | `mainnet` | `mainnet`, `testnet`, `devnet` |
| `DATABASE_URL` | compose | Injected; one Postgres |
| `NODE_MODE` | `external` | `external`, `stacks`, `full` |
| `DATA_DIR` | `/data` | Handler + runtime files |
| `API_PORT` | `3800` | Published as `127.0.0.1:3800` |
| `INDEXER_PORT` | `3700` | Observer bind |

Unknown keys and contradictions fail before ingest. `secondlayer start --print` shows the compose line.

## Verify and repair

```bash
secondlayer verify all --against <manifest>
secondlayer repair --against <manifest>          # plan
secondlayer repair --against <manifest> --apply
```

[Verified archive](/docs/archive#flags) owns flags and exit codes.

## Backup and upgrade

| Job | Rule |
| --- | --- |
| Backup | DB + pinned config + encrypted keys + handler manifests + height scope |
| Restore | wiped host + `secondlayer verify all` must be green |
| Upgrade | pin image → preflight disk/schema → backup → migrate → health → verify |
| Rollback | previous image; schema migrations are forward-only |

## Guardrails

App-only floor: 4 GB RAM, 80 GB disk. Full-node floor: 96 GB RAM, 1.5 TB disk. Postgres `max_connections` ≥ 50. Constrained boxes fail at start.

## Operations

```bash
docker compose pull && docker compose up -d
curl http://localhost:3800/health
export SL_API_URL=http://localhost:3800
secondlayer subgraphs deploy ./my-subgraph.ts
```

Keep `POSTGRES_PORT` / `INDEXER_PORT` on loopback. Set `INSTANCE_TOKEN` before binding `0.0.0.0`.

## What's not included

- Hosted accounts, billing, or a Secondlayer-operated subgraph
- Multi-tenant catalog
- Archive publisher (separate image)
