# Run Secondlayer

Postgres plus one Secondlayer container on your box. You run the node, or bundle it.

## Quick start

```bash
secondlayer init --network mainnet
# Copy .env.local secrets into docker/oss/.env

cd docker/oss
docker compose up -d
secondlayer observer --mode indexer --endpoint secondlayer:3700
secondlayer bootstrap --against <manifest>
secondlayer verify all --against <manifest>
```

API: `http://127.0.0.1:3800`. Health: `curl http://localhost:3800/health`.

<Callout type="warning" title="No light mode">

No Hiro-REST backfill. Run a node, bundle one, or restore from the [archive](/docs/archive).

</Callout>

## Profiles

| Profile | What runs |
| --- | --- |
| default | `postgres` + `secondlayer` (API, ingest, decoder, subgraph, webhooks) |
| `stacks-node` | + bundled Stacks, public Bitcoin |
| `full-node` | + bundled Stacks and bitcoind |

```bash
docker compose --profile stacks-node up -d
docker compose --profile full-node up -d
```

`NODE_MODE` is `external` | `stacks` | `full`. `full` needs `BITCOIN_RPC_PASSWORD`.

## Config

Six required non-secrets. Secrets come from `secondlayer init`.

| Key | Default | Notes |
| --- | --- | --- |
| `NETWORK` | `mainnet` | `mainnet`, `testnet`, `devnet` |
| `DATABASE_URL` | compose | Injected; one Postgres |
| `NODE_MODE` | `external` | `external`, `stacks`, `full` |
| `DATA_DIR` | `/data` | Handler + runtime files |
| `API_PORT` | `3800` | Published as `127.0.0.1:3800` |
| `INDEXER_PORT` | `3700` | Observer bind |

Unknown keys and contradictions fail before ingest. `secondlayer start --print` shows the compose line.

## Verify and repair

```bash
secondlayer verify all --against <manifest>
secondlayer repair --against <manifest>          # plan
secondlayer repair --against <manifest> --apply
```

[Verified archive](/docs/archive#flags) owns flags and exit codes.

## Upgrade

```bash
docker compose pull && docker compose up -d
curl http://localhost:3800/health
```

Migrations run at start under an advisory lock, and are forward-only. To roll back, pin the previous image tag — a schema that has already migrated forward stays migrated, so roll back the image, not the database.

## Backup

There is no `secondlayer backup` command yet. Back up with Postgres' own tools plus the files `secondlayer init` generated:

```bash
pg_dump -Fc "$DATABASE_URL" > secondlayer-$(date +%F).dump   # the index
cp docker/oss/.env  ./secondlayer-env-backup                 # secrets: keys + token
```

`.env` holds `INSTANCE_TOKEN`, `SECONDLAYER_SECRETS_KEY`, and `STREAMS_SIGNING_PRIVATE_KEY`. Losing it costs you more than losing the index — the index can be rebuilt from the [archive](/docs/archive), the keys cannot. Store it somewhere the database backup is not.

To restore, bring up an empty Postgres, `pg_restore` into it, put `.env` back, and confirm with `secondlayer verify all --against <manifest>` before trusting the result.

## Guardrails

Mainnet full history is large: the reference index measures ~500 GB, of which ~250 GB is `blocks`, `transactions`, and `events` and the rest is the decoded plane. Budget roughly 3 GB per 100k blocks for core datasets, or 6 GB with a broad decoder set, and remember those are averages over history that is much denser at the tip.

| Setup | RAM | Disk |
| --- | --- | --- |
| App services, external node, mainnet | 4 GB | 600 GB |
| App services, external node, testnet/devnet | 4 GB | 80 GB |
| Bundled node, mainnet | 96 GB | 2.5 TB |

Postgres `max_connections` ≥ 50. The bundled-node figure is dominated by the chain itself — Stacks chainstate alone measures 1.3 TB, and bitcoind is additional.

The runtime checks RAM, disk, and `max_connections` at start and refuses to boot below these floors, so an undersized box is told before it spends hours acquiring an index it cannot hold. Disk is measured as total filesystem capacity, not free space — a healthy instance legitimately fills most of its disk. If a dimension can't be measured, it's reported and skipped rather than assumed bad.

To run below a floor anyway:

```bash
SECONDLAYER_ALLOW_UNDERSIZED=true
```

That downgrades the refusal to a warning at every start. It exists so a box that was already undersized can still come back up after an upgrade — you keep the ability to run your own hardware, you just do it knowingly.

## Operations

```bash
export SL_API_URL=http://localhost:3800
secondlayer subgraphs deploy ./my-subgraph.ts
```

Keep `POSTGRES_PORT` / `INDEXER_PORT` on loopback. Set `INSTANCE_TOKEN` before binding `0.0.0.0`. Consumers running elsewhere: [Deploy](/docs/deploy).

## Console (optional)

A web UI for your instance, off by default:

```bash
docker compose --profile console up -d
secondlayer console   # opens http://localhost:3801/console
```

Screens, the token gate, and reverse-proxy recipes: [Console](/docs/console).

## Not in the box

- Multi-tenant catalog
- Archive publisher (separate image)
- Pay-per-call metering on your instance (the x402 rail was removed)
