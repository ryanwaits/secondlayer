# Webhooks API

Create webhooks, read their deliveries, and recover what a receiver missed. These endpoints are the `/api/webhooks` write plane of a self-hosted instance; the guide to receiving and verifying is [Webhooks](/docs/webhooks).

- Recover a down receiver: requeue dead events, or replay a block range.
