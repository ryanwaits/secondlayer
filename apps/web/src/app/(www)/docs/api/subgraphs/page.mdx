# Subgraphs API

Read your subgraph's tables, describe them, and deploy and operate them. Reading is under `/v1/subgraphs`; deploying and operating is the write plane under `/api/subgraphs` on a self-hosted instance. Envelope and filters are in [REST conventions](/docs/rest-api).
