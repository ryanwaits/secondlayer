# Streams API

The raw event firehose in chain order, a live tail over server-sent events, and the reorg history. Envelope and cursors are in [REST conventions](/docs/rest-api); most apps want the [Index API](/docs/api/index) instead.

<ApiPage slug="streams" />

export const agent = `
- Firehose: 'GET $SECONDLAYER_API_URL/v1/streams/events' with 'Authorization: Bearer $SECONDLAYER_API_KEY'; filter by types, contract_id, sender; page forward with next_cursor.
- Live tail: 'GET /v1/streams/events/stream' is server-sent events; resume with the last cursor you handled.
- Undo rows named in reorgs[] from the fork point; 'GET /v1/streams/tip' is where the chain ends now.
- One endpoint as markdown: 'https://www.secondlayer.tools/docs/api-reference/<anchor>.md', e.g. list-stream-events.
`;
