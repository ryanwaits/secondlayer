# filters

API surface of `@secondlayer/stacks/filters`.

Canonical chain-event filter vocabulary shared across Index, Streams, Subgraphs, and Webhooks.

## Exports

`CHAIN_EVENT_FILTER_TYPES`, `DECODED_EVENT_TYPES`, `fromSubgraphSource`, `makeChainEventFilter`, `on`, `assertAssetIdentifier`, `assetId`, `assertContractId`, `assertPrincipalish`, `hasWildcard`, `isPrincipal`, and filter/spec types (`ChainEventFilter`, `FtTransferSpec`, `PrintEventSpec`, `SbtcDepositSpec`, …).
