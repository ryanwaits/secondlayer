# pox5

API surface of `@secondlayer/stacks/pox5`.

PoX-5 Bitcoin Staking (SIP-045) — bonds, staking, lockup scripts, signer grants.

## Exports

`pox5` client extension, `isPox5Active`, `getPox5Activation`, `getPoxInfo`, `assertPox5Active`, cycle math (`burnHeightToRewardCycle`, `bondPhaseAtHeight`, …), lockup scripts (`buildLockupScript`, `buildLockupAddress`, …), signer grants (`computeSignerGrantHash`, `signSignerGrant`, `verifySignerGrant`), eligibility helpers, `POX5_ABI`, error helpers, and related constants/types.

See [PoX-5 guide](/guide/pox5).
